# Smart Parking Management System

## Run

Double-click `run-dev.bat`, or run this from the project root:

```bash
npm run dev
```

Open the app:

```text
http://localhost:5173
```

Backend API:

```text
http://localhost:5000
```

## Demo Accounts

- Admin: `admin@parking.com` / `admin123`
- User: `user@parking.com` / `user123`

## Manual Run

Terminal 1:

```bash
cd backend
npm start
```

Terminal 2:

```bash
cd frontend
npm run dev
```
