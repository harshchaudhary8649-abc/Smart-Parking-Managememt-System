# Smart Parking Backend

Local Express API for the Smart Parking Management System.

## Demo accounts

- Admin: `admin@parking.com` / `admin123`
- User: `user@parking.com` / `user123`

## Run

```bash
npm install
npm run dev
```

The API starts on `http://localhost:5000` and stores local data in
`backend/src/data/store.json`.
